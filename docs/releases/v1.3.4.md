# Production Toolkit 1.3.4

When NDI Job Configurator is not installed on this PC, Toolkit now searches connected IPv4 networks at startup and adds each verified server's **Open web UI** link below **Install**. Discovery starts independently of GitHub checks, shows results as they arrive, and leaves the dashboard usable. **Check for updates** searches again and removes stale links. Links are rechecked before opening in the default browser.

The read-only search verifies Job Configurator's identity on TCP 8091, covers complete /20–/30 subnets, and reports unsupported networks or incomplete scans. Local installation cancels the search and restores the normal local-app card. Remote discovery does not change NDI settings or install a local server.

Validation: 333 regression and WPF UI assertions pass, including full-subnet coverage, malformed/unrelated responses, bounded cancellation, stale-result removal and link placement at 100%, 200% and 250%. The release workflow also verifies installation, running-app upgrade, shortcuts and uninstall on its Windows runner.
