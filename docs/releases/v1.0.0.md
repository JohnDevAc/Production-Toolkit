Production Toolkit is a Windows launcher for Kiloview Environment Setup, NDI Job Configurator, Resolume Arena Configurator and NDI Configurator PC Agent.

- Install or update the latest stable or development release for each application.
- Check installed versions and launch existing applications.
- Download and verify the official installers, including the PC Agent's complete ZIP package.
- Open at a size that shows all four cards without scrollbars when the monitor has enough room. Smaller desktops retain accessible scrolling.
- Use each application's original icon alongside a new multi-resolution toolkit icon.

Download the standalone **.exe** to run the self-contained Windows x64 application, or use the ZIP for the executable and documentation together. No separate .NET installation is required.
