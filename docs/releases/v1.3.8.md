# Production Toolkit 1.3.8

The dashboard now includes **UDP to NDI** and **Test Card Generator** from JohnDevAc, with their original icons, installed-version status, release checks and launch controls. Six application cards fit in up to three columns, with scrolling retained on smaller displays. Up-to-date apps continue to hide the Update button.

UDP to NDI uses its official Windows x64 installer and detects the installed application. Test Card Generator uses its complete portable release ZIP, preserving its worker and private .NET runtime. Install verifies and prepares the package without launching TestCard or starting outputs. Updates use a fresh folder and retain the previous copy; a failed extraction or preference save preserves the previous launch location. NDI Runtime and FFmpeg remain separate prerequisites for TestCard's network outputs.

Validation includes 441 regression/UI assertions, verification of both projects' published packages, release filename/checksum checks, and isolated installer lifecycle checks. The Toolkit installer preserves its existing installation location and preferences; managed applications are installed only through their own card actions.
