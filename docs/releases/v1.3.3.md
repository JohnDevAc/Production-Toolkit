# Production Toolkit 1.3.3

PC Agent installations with missing or invalid per-user configuration now show **Setup incomplete** and offer **Complete setup**, even when their binary version is current. Matching installed Setup and Agent files can finish setup offline. Missing Setup requires the complete release package. Launch is enabled only after the configuration is valid, and a stale Launch action rechecks configuration before starting the agent.

The wrapper delegates configuration to the independent PC Agent Setup utility and retains its normal licence, adapter selection and UAC flow. No server or remote onboarding contract changes are required.

Validation: 312 Toolkit regression/UI assertions, the server's 22 regression and 8 frontend checks, installer package checks and both companion validation projects pass. The release workflow also verifies installation, running-app upgrade, shortcuts and uninstall on its Windows runner.
