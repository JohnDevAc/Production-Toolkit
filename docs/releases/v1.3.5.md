# Production Toolkit 1.3.5

Application cards now show **Installed version** and a simple **Up to date** or **Needs updating** status. The confusing setup-download and cache labels have been removed; the last release-check time is available by hovering over the update status.

When an application is current, its update button disappears and **Launch** or **Open setup** fills the action row. Incomplete installations still offer **Complete setup**, and environment component status remains visible.

Validation: 333 regression and WPF UI assertions pass, including layout checks from 100% to 250% scaling and narrow windows. The release workflow also verifies installation, running-app upgrade, shortcuts and uninstall before publishing the Windows installer.
