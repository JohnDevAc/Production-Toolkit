Production Toolkit 1.2 installs as a Windows application and can update itself.

- Run **Production-Toolkit-1.2.0-win-x64-Setup.exe**. Setup installs for your Windows account, creates desktop and Start menu shortcuts, and registers an uninstaller in Windows Installed apps.
- The default folder is `%LOCALAPPDATA%\Programs\Production Toolkit`. Updates retain your chosen installation folder, settings and caches.
- Startup and **Check for updates** check for a newer stable toolkit release. The prompt offers **Update and restart** or **Later**. Downloads are verified against GitHub's SHA-256 digest and the installer's embedded version before execution.
- Setup closes the existing toolkit gracefully, replaces the program, updates the same Windows app entry and relaunches it. Active managed-app downloads or installers must finish before maintenance. Older installers cannot downgrade a newer app, and Windows is not automatically rebooted.
- Uninstall closes the toolkit and removes its executable, app registration and both shortcuts. It retains preferences, caches, user-created files and the independently installed production applications.

Users of v1.0 or v1.1 portable releases should run this installer once, then use the installed shortcuts. Subsequent toolkit updates can be installed from its startup prompt.

Validation includes update selection and download verification, UI rendering at 100–250% scaling, and an actual installation lifecycle test covering shortcuts, a running-app upgrade, relaunch, downgrade protection and uninstall. The installer is self-contained; no separate .NET installation is needed.
