Production Toolkit 1.3 shows what Environment Setup actually installed and simplifies cards for uninstalled applications.

- Environment Setup now separates **Downloaded · up to date/out of date** from **Installed fully**, **Installed partially**, and **Not installed**.
- Component rows show KiloLink Server Pro's running state, the installed NDI Tools version, and NDI Discovery's service/listening state. The check also verifies the managed WSL distribution, setup configuration and startup watchdog. Hover for diagnostic details.
- Inaccessible components are marked unverified. A stopped service remains installed; a stopped WSL distribution is not started just to inspect its container. These local checks happen only at startup or **Check for updates**.
- Uninstalled apps show a large icon, app name, release-channel selector and one **Install** button. Downloaded setup files alone do not make an environment look installed. Partial environments offer **Complete setup** and retain their component details.
- Installation can reuse an existing current setup executable. A completed download is retained if the elevation prompt is cancelled.
- Cards have equal widths and matching heights within each row, preserving space for the environment details. Layouts were checked from 100% to 250% scaling, including mixed installed/uninstalled, partial and unverified states.

Run **Production-Toolkit-1.3.0-win-x64-Setup.exe**, or accept the toolkit's next update prompt. Setup preserves settings and shortcuts, closes the running toolkit and relaunches it after replacement. GitHub request caching and rate-limit handling remain in place.
