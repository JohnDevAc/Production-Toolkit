# Production Toolkit 1.4.0-dev.1

This development prerelease contains the same lifecycle maintenance, recovery and concise dashboard implementation as stable 1.4.0. Managed products retain their independent repositories, installers, settings and release channels.

Development Toolkit builds follow newer development prereleases for self-update. They do not automatically switch to stable. Installer verification distinguishes the semantic version `1.4.0-dev.1` from Windows numeric version `1.4.0.0`; a stable binary cannot satisfy the development release tag.

The accepted lifecycle implementation passed 991 regression/UI assertions, isolated installer checks and coordinated Windows VM installation/repair acceptance. Focused checks cover channel selection, version comparison and package metadata. Arena GPU/runtime validation and remaining unrun Windows fault scenarios are not claimed.
