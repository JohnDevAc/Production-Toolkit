Production Toolkit 1.1 gives every application card colours drawn from its own icon, with the same controls and spacing throughout.

- Icons are reread from installed applications during startup and update checks. Current project release icons, cached icons and bundled resources provide fallbacks.
- Card backgrounds, panels, borders, buttons and progress bars update with the icon. Button text retains readable contrast.
- Installed versions are reread during the same checks, detecting updates made inside an app and replacements at the same path. A newer persistent Environment Setup launcher takes precedence over an older saved setup.
- No background polling or reads when focus returns, a channel changes or an app launches. Completing an installation started from the toolkit performs an update check.
- Removed Download only, Locate app and Releases links from all cards. Routine launch, cancellation and completion messages have been removed; active progress and actionable errors remain.
- The footer, licence and executable metadata explicitly identify the application as proprietary, copyright © 2026 John Lightfoot, and free for non-commercial use.
- Startup sizing continues to fit all four cards without scrolling when the monitor work area permits, with vertical scrolling available on smaller desktops.

Validated with automated version, icon refresh/cache and palette contrast checks; live stable/development icon checks for all four projects; and a visual review of WPF layouts at 100%, 150%, 200% and 250% scaling, including narrow and busy/offline layouts. Native installer execution and physical monitor transitions remain separate hardware acceptance checks.

Download **Production.Toolkit.exe** for the standalone Windows x64 application, or the ZIP containing the executable and licence notices. No separate .NET installation is required.
