# Production Toolkit v1.3.1

App cards now refresh automatically when an installer closes. Installed versions, icons, available actions and local environment status update immediately using the saved release information, without another GitHub API request.

The refresh also runs after **Open setup**, repair, uninstall, and setup that exits with an error. All local cards are checked because Environment Setup can install the PC Agent as well. Installer errors and restart requirements remain visible.

Verified with 233 automated assertions, including harmless install/removal fixtures that exercise the real installer-exit path and the existing UI layout checks. The release workflow also validates the Toolkit install, upgrade and uninstall lifecycle.
