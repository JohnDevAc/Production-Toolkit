# Production Toolkit 1.3.6

The PC Agent card now shows **Running** or **Not running**. **Launch** is disabled while the matching agent is running in the current Windows session and becomes available again when it exits. If Windows prevents verification, **Running status unavailable** keeps Launch disabled until a later check can confirm it has stopped. These local checks preserve setup readiness and do not change Agent configuration.

Environment update status now follows the actual installed launcher. Downloading a newer setup and cancelling installation leaves **Needs updating** and the Update button visible. A verified saved setup remains reusable offline without being presented as an installed version. Current installed versions still hide the update button.

Invalid saved preference collections recover safely, preserving the original file and other valid preferences. The portable download and its checksum consistently use **Production.Toolkit.exe**; the installed executable and ZIP entry remain **Production Toolkit.exe**.

Validation includes 419 regression and WPF UI assertions, exact package filenames and checksums, and 21 installer lifecycle assertions. UI and installer fixtures use isolated startup and state. The installer updates only Production Toolkit, preserves its settings and installation directory, and does not update the managed applications.
